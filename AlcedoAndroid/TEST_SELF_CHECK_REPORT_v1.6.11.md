## 五、可接受的降级场景

| 场景 | 降级行为 | 验收等级 |
|-----|---------|---------|
| 无 Vulkan 设备 | 编辑器使用 CPU 路径，性能降低 | C |
| 无 API Key | AI 评级使用启发式 | C |
| 无 CLIP 模型 | AI 搜索提示下载 | C |
| 低内存 | 缩略图质量降低，缓存释放 | C |
| Doze 模式 | 后台任务暂停 | C |
| 数据库损坏 | 重建数据库，丢失历史 | C |
| 亮色主题 | 扩展色（示波器/通道）不变 | B |
| 动态色开启 | primary/secondary 跟随壁纸 | B |
