# Alcedo Studio v1.6.11 Android端用户交互操作体验测试计划

> 目标：100% 覆盖所有用户可触发的交互链路、手势、反馈、状态流转与体验感知。
> 关注点：触控交互精度、手势响应、视觉反馈完整性、状态机一致性、中断恢复、无障碍可达性。

---

## 一、交互体验验收标准

| 等级 | 定义 | 通过条件 |
|-----|------|---------|
| **A (完美)** | 交互丝滑、反馈即时、无卡顿、无跳变 | 响应 <100ms，视觉无撕裂，触感正确 |
| **B (可用)** | 交互可用，存在微小延迟或视觉瑕疵 | 响应 <300ms，主链路无阻塞 |
| **C (降级)** | 特定条件下降级运行 | 有明确提示，用户可理解当前状态 |
| **F (失败)** | 交互不可用、误触、数据丢失、ANR | 响应 >1s 或崩溃，阻塞发布 |

### 响应时间基准

| 交互类型 | 期望响应 | 最大容忍 |
|---------|---------|---------|
| 按钮点击 | <50ms | <200ms |
| 滑块拖动 | <16ms (60fps) | <33ms (30fps) |
| 页面切换 | <200ms | <500ms |
| 图片加载（缩略图） | <300ms | <1s |
| 图片加载（全尺寸） | <1s | <3s |
| 导出进度反馈 | <100ms | <500ms |
| AI 推理反馈 | 即时显示"处理中" | 无上限（有进度指示） |

## 二、模块交互用例

### U01 应用启动与首屏交互

#### UX-U01-001 Splash 过渡体验
- **前置条件**：应用冷启动
- **操作步骤**：
  1. 点击桌面图标
  2. 观察 Splash 屏 → 主界面过渡
  3. 检查 Splash 是否在首帧准备好后立即消失
- **预期结果**：
  - Splash 平滑过渡，无白屏/黑屏闪烁
  - Splash 持续时间 ≤ 隐私状态读取完成时间或 4s 超时
  - 过渡动画使用系统默认 fade
- **验收标准**：A — 无闪烁，过渡自然

#### UX-U01-002 首次启动隐私同意对话框交互
- **前置条件**：首次安装，未给过同意
- **操作步骤**：
  1. 启动应用，观察隐私对话框弹出
  2. 点击"接受"按钮
  3. 验证对话框消失动画
  4. 验证后续进入权限请求门
- **预期结果**：
  - 对话框居中显示，背景半透明遮罩
  - "接受"按钮点击后 100ms 内开始消失动画
  - 消失后无缝过渡到权限请求界面
- **验收标准**：A — 过渡自然，无闪烁

#### UX-U01-003 隐私同意拒绝交互
- **前置条件**：首次安装
- **操作步骤**：
  1. 启动应用，隐私对话框出现
  2. 点击"拒绝"按钮
  3. 验证应用行为
- **预期结果**：
  - 拒绝后云 LLM/遥测/崩溃报告立即关闭
  - 应用进入端侧模式，UI 可正常浏览
  - 设置页显示"已拒绝"状态
- **验收标准**：B — 拒绝后应用可用（端侧模式）

#### UX-U01-004 权限请求门交互
- **前置条件**：已同意隐私协议，未授予权限
- **操作步骤**：
  1. 隐私同意后，观察权限请求界面
  2. 点击"授权"按钮
  3. 系统权限对话框弹出
  4. 分别测试"允许"和"拒绝"
- **预期结果**：
  - 权限门界面显示权限说明文本 + "授权"按钮
  - 点击后系统对话框弹出，无延迟
  - 允许后立即进入主界面
  - 拒绝后显示权限说明 + 重试按钮
- **验收标准**：A — 流程顺畅

#### UX-U01-005 权限永久拒绝后的设置跳转
- **前置条件**：用户选择过"不再询问"
- **操作步骤**：
  1. 启动应用到权限门
  2. 验证显示"永久拒绝"提示
  3. 点击"打开设置"按钮
  4. 验证跳转到系统应用详情页
  5. 从设置返回应用
- **预期结果**：
  - 永久拒绝状态正确识别（仅在至少一次请求后）
  - "打开设置"按钮可见且可点击
  - 跳转到系统设置正确返回应用
  - 返回后权限状态自动刷新
- **验收标准**：A — 跳转和返回正确

#### UX-U01-006 外部图片 Intent 冷启动交互
- **前置条件**：从文件管理器分享图片到 Alcedo
- **操作步骤**：
  1. 在文件管理器中选择一张图片
  2. 分享到 Alcedo Studio
  3. 观察应用启动和图片接收
- **预期结果**：
  - 应用冷启动，经过 Splash → 隐私门 → 权限门
  - 图片 URI 被记录
  - 进入主界面后用户可导航到编辑器处理
- **验收标准**：B — 图片被接收（可能需用户手动导航到编辑器）

#### UX-U01-007 外部图片 Intent 热启动交互
- **前置条件**：应用已在后台运行
- **操作步骤**：
  1. 应用在后台
  2. 从文件管理器分享图片到 Alcedo
  3. 验证 `onNewIntent` 被调用
- **预期结果**：
  - 应用从后台恢复
  - 图片 URI 被记录，不重复创建 Activity
  - Logcat 输出 "External image intent received"
- **验收标准**：A — 不重建 Activity

#### UX-U01-008 加载超时回退
- **前置条件**：模拟 DataStore 读取卡顿
- **操作步骤**：
  1. 启动应用
  2. 等待 4 秒（LOAD_STATE_TIMEOUT_MS）
  3. 验证超时回退行为
- **预期结果**：
  - 4 秒后 Splash 消失
  - 回退到"未同意"状态，显示隐私对话框
  - 不永远卡在加载界面
- **验收标准**：A — 超时回退正确
